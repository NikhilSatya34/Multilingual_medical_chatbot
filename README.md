# 🩺 Multilingual Medical Chatbot

An AI-powered Multilingual Medical Chatbot that helps users interact in multiple languages and receive healthcare-related information through a conversational interface.

## 🚀 Features

- 🌍 Multilingual Language Support
- 🤖 AI-Powered Medical Question Answering
- 💬 Interactive Chat Interface
- 🔄 Real-Time Translation
- 🏥 Healthcare Information Assistance
- 📱 User-Friendly Interface
- ⚡ Fast Response Generation
- 🔐 Secure API Integration

## ⚙️ Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/NikhilSatya34/Multilingual_medical_chatbot.git

cd Multilingual_medical_chatbot
```

### 2️⃣ Create Virtual Environment

```bash
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### Linux / Mac

```bash
source venv/bin/activate
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Configure Environment Variables

Create a `.env` file in the root directory.

```env
API_KEY=your_api_key_here
```

### 5️⃣ Run the Application

```bash
python app.py
```

Open:

```bash
http://127.0.0.1:5000
```
